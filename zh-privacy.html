网站访问分析

本网站使用 Google Analytics 4 了解访问和使用情况。收集的信息可能包括页面浏览、会话活动、大致所在地区、浏览器和设备信息、页面滚动、外部链接点击、站内搜索、视频互动及文件下载。

Google Analytics 可能使用 _ga 和 _ga_<container-id>等第一方 Cookie 来区分访客和会话。广告存储、广告用户数据及广告个性化功能均已设置为不启用。

有关 Google 如何处理信息，请参阅 Google 如何使用来自采用其服务的网站或应用的信息。

Cookie 设置

您可以在浏览器设置中阻止或删除 Cookie。阻止分析 Cookie 后，我们可获取的网站使用情况信息可能会受到限制。

Gmail 预约咨询处理

为查看 AIRE SPA 工作 Gmail 账号收到的预约咨询，我们使用 Gmail API 的只读权限。系统读取新邮件的发件人姓名和邮箱地址、主题、正文预览、接收时间及邮件标识符，并将邮件分为预约咨询、待审核和非预约邮件。

只有被归类为预约咨询的邮件才会以通知形式显示给预约管理人员。只读权限不会用于发送、修改或删除邮件，也不会更改 Gmail 中的已读状态。处理后的信息仅供有访问权限的管理员和预约工作人员查看。

身份验证信息通过 Cloudflare 的服务器机密配置管理，分类后的咨询信息存储在 Supabase 中。从 Google API 获取的信息，其使用和传输遵循 Google API 服务用户数据政策及其有限使用要求。
